REST API Reference

Method Path Description Permissions
POST /api/auth/register Register a new user Public
POST /api/auth/login Authenticate and receive JWT token Public
GET /api/users List all users Authenticated
PUT /api/users/{id}/role Change a user's role Admin only
POST /api/projects Create a project Manager, Admin
GET /api/projects List projects Authenticated
POST /api/projects/{id}/members Add member to project Project Manager, Admin
POST /api/sprints Create sprint Project Manager, Admin
POST /api/sprints/{id}/start Start sprint (PLANNED → ACTIVE) Project Manager, Admin
POST /api/sprints/{id}/complete Complete sprint (ACTIVE → COMPLETED) Project Manager, Admin
POST /api/tasks Create task Developer, Manager, Admin
POST /api/tasks/{id}/transition Transition task status Workflow rules & roles
GET /api/tasks?projectId=&status=&priority= List tasks with filters Project Member, Admin
POST /api/tasks/{taskId}/comments Add comment to task Any Project Member (including Viewer)
GET /api/audit-logs/projects/{projectId} Read audit log per project Project Member, Admin
GET /api/audit-logs/tasks/{taskId} Read audit log per task Project Member, Admin
